# TV apps — store listings (روابط الذكر الحكيم)

All three TV apps are thin launchers that open https://rawabit-alziker-alhakim.vercel.app/#/room?view=tv
(the TV screen with a QR code; the phone becomes the remote). Content updates never need a store update.

## Packages
- LG webOS: tv-apps/app.rawabit.quran.tv_1.0.0_all.ipk (App ID app.rawabit.quran.tv) — LG Seller Lounge, free.
- Android TV / Google TV / Fire TV: built by GitHub Actions ("Build Android TV app") → artifact rawabit-androidtv (APK for testing, AAB for Google Play). Package app.rawabit.quran.tv. Google Play developer account: USD 25 once. Amazon Appstore: free, accepts the APK.
- Samsung Tizen: source in tv-apps/tizen (config.xml, index.html, icon). Must be signed in Tizen Studio with a Samsung certificate (Samsung account), then submitted in Samsung Apps TV Seller Office.
