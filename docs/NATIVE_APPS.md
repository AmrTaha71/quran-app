# التطبيقات الأصلية (أندرويد + آيفون) — الأذان والمنبه بدون فتح التطبيق

الفرع: `native-app` (فوق `main`). الكود الأصلي: `src/lib/nativeAlarm.ts` + Capacitor.

## ما يعمله
- الأذان لكل صلاة والتطبيق مقفول (إشعار محلي بنظام الجهاز).
- منبه الفجر: عادي (إشعار واحد) أو ذكي (سلسلة إشعارات كل دقيقة: أندرويد ٣٠ دقيقة، آيفون ٦). عند الضغط على الإشعار تفتح شاشة الأسئلة، وعند حل ٣ أسئلة تُلغى بقية السلسلة.
- 12 نغمة مولّدة (`alarm_<id>.wav`)، تُختار من الإعدادات.
- تفعيله من: الإعدادات ← الأذان ← «تفعيل الأذان والمنبه والتطبيق مقفول» (يطلب الأذونات).

## حدود لا يتجاوزها النظام (بصراحة)
- الإشعار لا يدور في حلقة داخل النظام: لذلك «الذكي» = تكرار كل دقيقة، لا رنين متواصل.
- آيفون: أقصى مدة لصوت الإشعار ٣٠ ثانية، وأقصى ٦٤ إشعارًا معلّقًا (لذلك أيام أقل).
- تسجيلاتك الصوتية («قوم صلّي الفجر») تعمل داخل التطبيق بعد الضغط على الإشعار، ولا يمكن استخدامها كصوت إشعار أصلي، فيرنّ الإشعار بالنغمة المختارة (الكلاسيكي إن كانت المختارة تسجيلًا).
- «Critical Alerts» (تخطي الصامت) في آيفون تحتاج إذن خاص من آبل؛ بدونه الإشعار يحترم وضع الصامت وعدم الإزعاج.

## خطوات البناء (على الماك بوك)
1. `npm i && npm run build && npx cap sync`
2. توليد الأصوات (جاهز في الفرع، أعد التشغيل عند تغيير النغمات): `node scripts/gen-alarm-sounds.mjs`
3. **أندرويد:** `npx cap open android` ← Android Studio ← Run. الأصوات في `res/raw` جاهزة.
4. **آيفون:** `npx cap open ios` ← Xcode ← اسحب مجلد `ios/App/App/sounds` إلى مشروع App (Copy items + target App) ← فعّل Signing.
5. صوت الأذان (اختياري): ضع مقطع «الله أكبر الله أكبر» باسم `adhan_short.wav` في `android/app/src/main/res/raw` وفي `ios/App/App/sounds` (≤ 30 ث). لا نقصّ الملفات المرخّصة ND؛ الأفضل تسجيل بترخيص يسمح أو إذن.
6. المتجر: أندرويد يحتاج أن يُصنَّف كتطبيق أذان/منبه ليقبل إذن `USE_EXACT_ALARM`؛ آيفون يحتاج مراجعة آبل (إشعارات محلية فقط، لا خلفية).
